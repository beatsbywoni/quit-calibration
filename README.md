# quit-calibration

Preregistration, code, and pilot summaries for the study
**"Quitting winnable contests? The calibration of resignation in online chess and surrender in League of Legends"**
(Hongwon Jeong, Hanyang University ERICA, ORCID 0009-0003-7908-7478).

- `prereg/preregistration_v1.0.md`: the registered plan (release `v1.0-prereg`). Later changes are recorded as deviations, not edits to this file.
- `code/`: pilot scripts and the confirmatory League of Legends collector. Standard library only, except `pilot_lol.py` (NumPy).
- `pilot/`: aggregate pilot outputs that informed the hypotheses (Lichess, first day of October 2026; 2,811 KR ranked solo matches). Pilot data are excluded from confirmatory analyses.
- `AI_USAGE_LOG.md`: log of generative AI use (in Korean).

Data: chess games come from the Lichess open database (CC0). League of Legends data come from the Riot Games API; raw API data are not redistributed, and only aggregates and match identifiers will be shared. No API key is stored in this repository.
